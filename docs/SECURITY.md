# 安全

- HTTP 明确允许但持续警告；HTTPS 使用系统信任锚，不提供忽略证书错误开关。
- 令牌加密存储，不写日志、剪贴板、崩溃信息或状态文档。
- `signing/` 整体在 `.gitignore` 内（私钥 `.p12`、证书 `.cer`、Profile `.p7b` 绝不入库）。
- 应用数据不参与云备份，避免令牌密文离开生成密钥的设备。
- App 不拥有服务器绝对路径，只处理 `rootId + relativePath`。
- App 不调用管理 API、DSH 私有 `/api` 或无约束 RPC 转发。
- UI 依据设备 scope 禁用写入、删除和聊天提交操作；服务器仍是最终授权边界。
- 供应商列表只读取凭据是否存在及其来源，不读取密钥正文；新增密钥仅发往插件，输入框不回填服务器值。
- 状态文档、开发日志与示例输出中的设备令牌一律脱敏。
