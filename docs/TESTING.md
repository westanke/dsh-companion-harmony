## 纪律

- 修 bug 必须带回归用例。
- 测试文件命名与被测模块对应，夹具集中在 `test/cases/`。
- 不许为凑数加空断言测试。
- **单测绿 ≠ 行为对**：手势、键盘、表格渲染、表格列宽、断流重连一律真机确认。
