## 一、中文（简体）

### 一句话简介（13 / 17）

```text
远程连接你的 DSH 助手
```

### 应用介绍

```text
DSH 伴侣是一款连接你自己部署的 dsh 服务的移动端客户端，把运行在电脑上的 AI 会话搬到手机上，让你不必守在电脑前，也能查看进度、继续对话、处理审批。

为什么需要它
dsh 服务运行在电脑上，人一离开座位就断了联系：进度看不到、审批点不了、会话接不上。本应用把「配置导入」作为主要连接方式——在电脑上生成一行文本，通过任意聊天工具发给自己，到了外面粘贴进应用即可完成配对，不需要人和电脑处在同一网络。

主要功能
· 连接管理：可同时保存局域网、虚拟网、公网等多个地址，按需切换
· 会话浏览：查看历史会话、实时消息流、AI 的思考过程与工具调用记录
· 交互操作：提问、回复、处理待审批操作、回答 AI 的追问
· 文件查看：浏览与编辑工作区文件，在应用内预览 HTML、图片等文件
· 模型与插件：管理模型供应商、切换会话所用模型、启停插件
· AI 内容标识：对 AI 生成的文本内容标注「内容由 AI 生成」
· 界面偏好：支持深色模式并跟随系统主题，界面为中文

使用前提
本应用是客户端工具，自身不提供内容生成服务，也不提供信息发布或即时通讯服务；需要连接你在自己电脑上部署的 dsh 服务端（并安装 dsh-remote-bridge 插件）后才能使用。请先在电脑上完成服务端部署，再通过配置导入或配对码连接。

服务端插件安装命令：
dsh plugin --profile web add dsh-remote-bridge
```

## 二、English

### Tagline (13 / 17 characters)

```text
DSH on the go
```

### App description

```text
DSH Companion is a mobile client for your own self-hosted dsh service. It brings AI sessions running on your computer to your phone, so you can follow progress, continue conversations, and handle approvals without staying at your desk.

Why it is needed
The dsh service runs on your computer, so once you leave your desk you are cut off: you cannot see progress, cannot act on approvals, and cannot pick up a session. This app uses config import as its main connection method — generate a single line of text on your computer, send it to yourself through any chat app, and paste it into the app when you are out. Your phone and computer do not need to be on the same network.

Key features
- Connection management: keep several addresses (LAN, VPN, public network) at once and switch between them
- Session browsing: view past sessions, the live message stream, the AI's reasoning and tool-call records
- Interaction: ask questions, reply, handle pending approvals, and answer the AI's follow-up questions
- File viewing: browse and edit workspace files, and preview HTML, images and other files in the app
- Models and plugins: manage model providers, switch the model a session uses, enable or disable plugins
- AI content labelling: AI-generated text is marked "Content generated by AI"
- Look and preferences: dark mode that follows the system theme; Chinese user interface

Requirements
This app is a client tool. It does not itself provide content generation, publishing or messaging services. It works only with your own self-hosted dsh server with the dsh-remote-bridge plugin installed. Deploy the server on your computer first, then connect by config import or a pairing code.

Server plugin installation command
dsh plugin --profile web add dsh-remote-bridge
```

## 三、填写须知

### 3.1 一句话简介为什么用缩写

「远程连接你的 DSH 助手」共 **13 个字符**，在 17 字硬上限内。
若写全服务端产品名会到 **25 个字符**，提交会被打回，因此两版均用自有的 `DSH` 缩写。

### 3.2 命名与品牌口径（2026-10-16 起）

- **应用名统一为「DSH 伴侣」/「DSH Companion」**，与包内 `app_name` 完全一致。
- **应用信息（名称、图标、介绍、截图、录屏）中不得出现任何第三方产品名或商标。**
- 提到服务端时写「dsh 服务端」（命令行的 `dsh` 是工具名，不是第三方产品名）。
- 截图录制后需**逐张检查**：会话标题、插件名、文件路径等**服务端返回的数据**可能自带第三方
  品牌字样，出现在截图里同样会被视为「应用内容相似」，建议滚动/换图规避。
- **2026-10-17 1.0.3 重拍实测（如实记录）**：会话标题、插件描述等**服务端真实数据**里仍有第三方
  品牌字样 —— 如会话标题「…DeepSeek Harness…」、插件描述「GenUI for DeepSeek Harness」、
  工作区路径含 `harness`。它们来自用户自建服务端返回的数据、**不是本应用的文案或标题**；
  本轮未对数据做清除（会话列表 49 条里品牌标题分散，任意滚动窗口都无法全避开）。
  如需彻底规避，须由服务端侧改数据或改会话标题后再重拍。

### 3.3 服务端插件版本

本应用需要服务端安装 `dsh-remote-bridge` 插件（旧名 `dsh-workspace`），
版本 **不低于 2.0.4** —— 低于该版本缺少路径解析接口，会话内文件功能会失效。

安装命令：

```bash
dsh plugin --profile web add dsh-remote-bridge
```

### 3.4 审核要点

1. **必须写明「需自建服务端」**。本应用是客户端，审核员打开后若无服务端可连，
   会被判「功能不可用」而驳回。「使用前提」段落即为此而写，不要删除。
2. **必须写明「自身不提供内容生成服务」**。生成行为发生在用户自建的服务端上，
   本应用只是连接工具 —— 这是回应「实名认证」「AI 生成合成服务」两条审核意见的定性依据。
3. **必须上传演示录屏**（AGC「版本信息 > 应用审核信息 > 自测文件」）：
   应用的后端依赖已部署服务端，不录屏审核员无法遍历使用。
4. **AI 功能声明要与其一致**：勾选「涉及 AI 生成合成服务」，与第 2 条并不矛盾 ——
   涉及 AI 内容 ≠ 自己提供服务，两者都要如实填写。
5. **避免绝对化用语**（最、第一、永久）、不写「免费」、不做竞品对比、不出现「测试版 / 内测」字样。
