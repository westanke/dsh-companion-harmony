# DSH 伴侣 1.0.0 发版说明

- **版本**：1.0.0（`versionCode` 1000000）
- **日期**：2026-10-15
- **平台**：HarmonyOS 6.0 及以上（`compatibleSdkVersion` 5.1.0(18)）
- **设备**：phone / tablet / 2in1
- **产物**：`dsh-companion-harmony-1.0.0-release-signed.app`（AGC 上架）
- **许可**：AGPL-3.0

---

## 这是什么

DeepSeek Harness 的 HarmonyOS **原生客户端**。把运行在电脑上的 AI 会话搬到手机上，
不必守在电脑前也能查看进度、继续对话、处理审批。

## 使用前提（必读）

本应用是**客户端**，不自带任何 DSH 能力，必须连接你自己部署的服务端：

1. 电脑上已部署 **DeepSeek Harness**；
2. 服务端安装插件 **`dsh-remote-bridge` ≥ 2.0.4**（旧名 `dsh-workspace`）：

   ```bash
   dsh plugin --profile web add dsh-remote-bridge
   ```

3. 通过**从电脑导入配置**或**一次性配对码**完成连接。

## 首次发布内容

- **连接**：配置导入（`DSH1:` 载荷）、一次性配对码、多主机保存、局域网 / 虚拟网 / 公网
  端点切换与自动选路、冷启动自动重连
- **会话**：会话列表、实时消息流、思考过程与工具调用记录、审批处理（含全权限二次确认）、
  AI 追问应答、上下文注入来源显示
- **渲染**：Markdown 原生渲染（标题 / 列表 / 引用 / 代码块 / **表格** / 分隔线 / 链接 /
  行内样式）、GenUI 卡片原生组件树
- **文件**：授权根目录浏览、带行号的编辑器、Markdown 源码与预览、图片预览、
  二进制降级预览、上传与下载
- **插件与模型**：插件清单与启停、供应商管理、模型清单与会话模型切换
- **界面**：深色模式跟随系统、中文界面（英文接口已预留）

## 已知限制

| 限制 | 说明 |
|---|---|
| `useWebChat` 设置开关 | 本版聊天页为原生实现、无内置网页版，**拨动它不会改变界面**（开关保留 + 页面已注明） |
| 剪贴板 | 未申请剪贴板权限（该权限为受限权限，申请后无法安装）；读取失败时给出提示，长按粘贴走系统能力 |
| 仅中文 | 英文接口与资源键已预留，界面文案尚未提供英文 |
| 平板 | 已声明支持平板，但尚未做平板专项适配与验证 |

## 安装

- **应用市场渠道**：直接安装（`.app` 已用发布证书与发布 Profile 签名，无设备白名单限制）。
- **开发者本地**：需用调试证书签名的 `.hap`（发布签名包无法通过 `hdc` 安装，
  系统报 `not trusted app source`）。
